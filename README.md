🔹 Task 1: Website Wireframe Design

The task involves designing the basic structure and layout of an e-learning website before developing the actual UI. The wireframes show where different elements such as headings, buttons, images, course cards, navigation, and content will be placed.

Your task contains 3 main wireframes:

Landing Page – Wireframe
Contains the website navigation/header.
Main hero section with a heading like “Learn something new today.”
A call-to-action button.
Featured course categories.
“How It Works” section explaining the learning process.
Footer/navigation area.
Course Detail – Wireframe
Shows detailed information about a particular course.
Course title and description.
Course preview/video section.
Course content/modules.
Course price and enrollment button.
“About this course” section.
Instructor information.
Course Catalog – Wireframe
Displays available courses.
Category/filter sidebar for finding courses.
Course cards containing course image, title, instructor/category, rating/details, and price.
Pagination/navigation at the bottom.
🎯 Main Objective

The purpose of this task is to plan the website's user interface and user experience before actual development. A wireframe focuses on layout, structure, navigation, and functionality rather than colors, graphics, and final visual styling.
